Planejar → Rascunhar → Criticar → Refinar → Entregar. Várias chamadas ao Gemini trabalham em cadeia — se uma chave travar por limite, a próxima assume. Configure suas chaves para começar.

Configurar chaves Gemini

Cole uma ou mais chaves (uma por linha ou separadas por vírgula). Elas ficam salvas só no seu navegador (localStorage) e são enviadas apenas para a API do Google. Se uma chave bater o limite de uso, o RELÊ roda automaticamente para a próxima.

Se der erro 401/403: confira se copiou a chave inteira (sem espaços/aspas), se ela é do Google AI Studio (aistudio.google.com/apikey) e se não tem restrição de "HTTP referrer" — chaves restritas bloqueiam chamadas feitas de um arquivo local.
