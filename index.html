Modelo & pedido
As chaves ficam só no seu navegador e vão direto pra API do Google (generativelanguage.googleapis.com) — nenhum outro servidor no meio. As 11 etapas revezam entre as chaves que você adicionar; com poucas chaves, a mesma é reaproveitada mais vezes (com pausas entre chamadas pra respeitar o limite gratuito).
