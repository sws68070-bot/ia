orquestrador multi-agente · gemini api

Várias chaves da API Gemini trabalhando juntas: uma planeja, várias escrevem o arquivo em seções, uma ou mais revisam e corrigem, e no final tudo é unido em um único arquivo pronto para baixar.

01 · Chaves de API — adicione uma ou mais

As chaves ficam apenas na memória desta aba (não são salvas) e são usadas para chamar generativelanguage.googleapis.com diretamente do seu navegador. Com 1 chave o pipeline roda sequencialmente; com várias, as seções são geradas em paralelo (uma planeja, várias escrevem seções ao mesmo tempo, outras revisam e corrigem juntas). Cada chave tem um papel: "geração + verificação" entra no rodízio dos dois tipos de tarefa; "só geração" nunca é chamada para revisar; "só verificação" fica reservada para revisar/corrigir e não escreve seções — útil para dedicar uma chave inteira a manter a qualidade do arquivo enquanto as outras produzem código. O arquivo cresce seção por seção — por isso não há limite real de linhas (funciona para 9000+ linhas ou no modo infinito), e a verificação final é feita em lotes pequenos para não gastar tudo de uma vez. Trate suas chaves como senhas.
